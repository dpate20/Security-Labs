# 🛡️ Security Labs

Welcome to my **Security Labs** repository — a growing collection of hands-on cybersecurity labs, technical investigations, and security research write-ups.

This repository documents my practical experience with network traffic analysis, packet crafting, intrusion detection, and security monitoring. Each lab highlights the tools used, methodology, observations, and security concepts explored.

The goal is to demonstrate my technical skills, document my learning process, and build a portfolio relevant to **cybersecurity, security engineering, and security operations (SOC)**.

## ⚖️ Ethics & Authorization

✅ All security testing is performed in controlled, authorized environments or as part of approved academic coursework.

🚫 No unauthorized scanning, exploitation, or testing of production systems.

## 🔬 Hands-On Cybersecurity Labs

| Lab | Topic | Tools & Technologies | Description | Documentation |
|---|---|---|---|---|
| Lab 01 | Network Traffic Analysis | Wireshark, DNS, HTTP, TCP/IP | Analyzed captured network traffic to identify DNS queries, HTTP requests, destination IP addresses, and web server information. | [View Lab](reports/Lab_01_Wireshark.pdf) |
| Lab 02 | Network Packet Crafting | Python, Scapy, Kali Linux | Developed a Python script to construct DNS queries, ICMP echo requests, and TCP SYN packets to explore network communication at the packet level. | [View Lab](reports/Lab_02_NetworkPackets.pdf) |

### Key Skills Demonstrated

- **Network Traffic Analysis:** Investigating DNS, TCP, and HTTP communication using Wireshark.
- **Network Programming:** Constructing and transmitting network packets using Python and Scapy.
- **Intrusion Detection:** Writing Snort signatures and interpreting network security alerts.
- **Protocol Analysis:** Understanding packet headers, DNS resolution, ICMP requests, and TCP SYN packets.
- **Technical Documentation:** Recording methodologies, evidence, findings, and limitations.
